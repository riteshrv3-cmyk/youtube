description: Turn an approved script into a finished vertical video using Higgsfield and Adobe MCP tools.
---

1. For each beat, generate a 9:16 visual with the video/image generation tools (Higgsfield). Keep a consistent look; record prompts in `output/prompts/`.
2. Generate Hinglish voiceover (audio tool). Verify Hindi pronunciation by listening to the sample before batch generation.
3. Make a thumbnail/cover with Adobe tools (start with the Adobe init tool), big 3-5 word Hinglish text.
4. Assemble with captions burned in (word-level, high contrast). Final export: 1080x1920, under 45s.
5. Confirm credit/cost with the user before any expensive batch; prefer short test clips first.
6. Save file list and prompts to `output/` and ask the human for final approval.
