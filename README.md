# AI Hinglish Channel — Claude-run YouTube pipeline

Goal: reach ~$1,000 (~₹85,000, check the live rate) in 15 days from a new channel, with Claude doing research, scripts, visuals, voice, captions, scheduling and the sales funnel. The human publishes and approves payments.

Revenue does NOT come from AdSense (Partner Program needs 1,000 subs plus 4,000 watch hours or 10M Shorts views). It comes from an owned offer the channel drives people to.

## Layout
- `CLAUDE.md` — operating rules for Claude in this repo
- `strategy/PLAN.md` — niche, offer, revenue math, 15-day calendar
- `strategy/calendar.csv` — day-by-day publishing plan
- `.claude/skills/` — reusable skills (research, script, visuals, publish, funnel)
- `scripts/` — ready-to-shoot Hinglish Shorts scripts
- `site/index.html` — landing page for the offer (deploy to any static host)
- `output/` — generated assets and logs (created as work happens)
